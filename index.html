Frequently Asked

Are you available as a freelance Ruby on Rails developer?

Yes — I'm available for remote freelance Ruby on Rails development, contract work, and consulting engagements worldwide. I accept project-based, hourly, and monthly retainer arrangements.

What Ruby on Rails services do you offer?

I offer full-stack and backend Ruby on Rails development including REST API design, microservices architecture, SaaS platform development, performance optimisation, AWS and Azure cloud infrastructure, CI/CD pipeline setup, and fractional tech lead services.

Which Rails versions and technologies do you work with?

I work with Rails 5, 6, and 7 including Hotwire/Turbo. My stack includes Ruby on Rails, PostgreSQL, MySQL, Redis, Sidekiq, RSpec, Devise, AWS, Azure, Docker, and GitHub Actions.

Do you work with startups or only large enterprises?

Both. I work with early-stage startups building their first Rails product, scale-ups migrating off a monolith, and enterprises needing a senior contract Rails engineer or fractional tech lead.

Are you available for remote work across different time zones?

Yes, I'm fully remote and available across US (EST/PST), EU (CET/GMT), and APAC time zones.

Do you only take Ruby on Rails work, or plain Ruby projects too?

Both. I'm a Ruby developer first — Rails is the framework I use most, but I also take on plain Ruby work: CLI tools, background-processing scripts, gem development, and backend services that don't need a full Rails stack. If your project is Ruby but not Rails, I'm still a fit.

Is a "RoR developer" different from a "Ruby on Rails developer"?

No — RoR is simply shorthand for Ruby on Rails. Whether you search for a RoR developer, a RoR freelancer, or a Ruby on Rails developer for hire, you're looking for the same skill set, and I fit all three.
